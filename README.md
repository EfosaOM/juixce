# JUICE — Chukwudi Charles Ezeani

Personal site for music producer, creative director, and audio engineer **Chukwudi Charles Ezeani (Juice)**.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Contents

- `index.html` — single-page portfolio
- `styles.css` — visual system
- `script.js` — scroll reveals and footer year
